# Flux 2.4 release and platform guide

## Release contents

Flux 2.4.1 keeps the Windows x64 installer and portable package, the Linux x86_64 RPM, Chromium and Firefox extension archives, source archive, SHA-256 checksums and signed updater metadata. The extension archives are built from the shared `extension/` sources; Firefox-specific bundles are generated by `npm run build:extensions`.

## Windows

The Windows release workflow validates the version across the npm, Cargo, Tauri and extension manifests, builds the desktop and native host, packages the browser extensions and runs the installer, native-window, Firefox, Chromium handoff, torrent and media regression checks. The 2.4.1 installer includes the English/Turkish language selector. Windows binaries have updater signatures; Authenticode publisher signing remains a separate SignPath process and must not be claimed unless the workflow reports it as enabled and successful.

## Linux RPM

Build on Ubuntu 24.04 or a compatible baseline with Tauri, Rust, Node, GTK/WebKitGTK, OpenSSL, Boost and RPM tooling installed:

```bash
bash scripts/build-linux-release.sh
```

The script reads the package version from `package.json`, builds the native torrent bridge and the RPM, then creates `release/Flux-<version>-linux-x86_64.rpm`. The Linux workflow installs that exact package in Fedora 43 and exercises its dependencies, desktop startup, native messaging, HTTP transfer and torrent integration. RPM installation and upgrades use `dnf`; the Windows in-app updater does not install Linux packages.

The target is Fedora x86_64 with WebKitGTK 4.1, OpenSSL 3, Python 3.10+ and Node 20+. Other RPM distributions may require dependency adjustments. Flatpak/Snap browser confinement is outside this package's integration guarantees.

## Browser extensions

The Chromium, Firefox 120+ and Firefox 140+ archives are separate from the desktop installer. Install the matching archive, enable the extension, launch Flux once to register its per-user native host and refresh existing tabs. Standard Firefox permanent installation requires Mozilla signing; the ZIP is suitable for temporary/developer installation.
