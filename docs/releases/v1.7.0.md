# Flux 1.7.0

English · Türkçe

## English

Flux is an open-source Windows download manager built with Rust, Tauri and React. This release combines persistent segmented downloads, browser integration and media processing in separate desktop windows.

### Downloads and media

- Automatic connection selection or 1–32 connections, dynamic HTTP Range splitting, pause/resume, bounded retries and SHA-256 checks.
- Persistent history with added, first-started and completed times; priority queues, schedule, speed limits and batch URL import.
- HLS, DASH and TS; MP4/MKV video, MP3/MKA audio, subtitles, chapters and optional audio normalization.
- YouTube quality selection, captured accessible media sources and conditional signed-source renewal. Finite media can display estimated size, progress and remaining time.

### Desktop and browsers

- Separate approval, progress and settings windows; search, sorting, multi-selection and completed-file drag-out.
- Optional category folders, clipboard queueing, Windows startup and cancellable completion actions.
- Twenty interface languages with searchable selection and Arabic/Urdu RTL layout.
- Chrome/Chromium and Firefox companion extensions, authenticated Native Messaging and explicit local transfer consent.
- Viewport-wide video-button dragging, remembered positions, unclipped panels, outside-click dismissal and safe handling of video/navigation changes.

### Packages and validation

Choose the Windows installer or portable ZIP. Chromium, Firefox 140+ and Firefox 120–139 extension packages are separate. `SHA256SUMS.txt` records the identity of the six distributions.

The latest repair passed 39 extension and six UI data tests, controlled real-Chromium layout checks, Firefox 120/157 native integration and the rebuilt Windows installer suite. The unchanged core retains its separately dated 82-test baseline. Evidence and test scope are included in the source package.

Current local binaries are unsigned; Windows may show a publisher or SmartScreen warning. Chromium builds load unpacked. Firefox packages need Mozilla signing for permanent installation in standard Firefox. Browser-store publication is separate. DRM and authentication challenges are not automatically bypassed; media availability depends on the source.

## Türkçe

Flux; Rust, Tauri ve React ile geliştirilmiş, açık kaynaklı bir Windows indirme yöneticisidir. Bu sürüm kalıcı çok parçalı indirme, tarayıcı entegrasyonu ve medya işlemeyi ayrı masaüstü pencerelerinde bir araya getirir.

### İndirme ve medya

- Otomatik bağlantı seçimi veya 1–32 bağlantı, dinamik HTTP Range bölünmesi, duraklatma/sürdürme, sınırlı yeniden deneme ve SHA-256 kontrolü.
- Eklenme, ilk başlatma ve tamamlanma zamanlarıyla kalıcı geçmiş; öncelikli kuyruk, zamanlama, hız sınırı ve toplu bağlantı ekleme.
- HLS, DASH ve TS; MP4/MKV video, MP3/MKA ses, altyazı, bölüm bilgisi ve isteğe bağlı ses normalizasyonu.
- YouTube çözünürlük seçimi, yakalanan erişilebilir medya kaynakları ve desteklenen adreslerde yenileme. Sonlu medyada yaklaşık boyut, ilerleme ve kalan süre gösterimi.

### Masaüstü ve tarayıcı

- Ayrı onay, ilerleme ve ayar pencereleri; arama, sıralama, çoklu seçim ve tamamlanan dosyaları sürükleme.
- İsteğe bağlı kategori klasörleri, panodan kuyruğa ekleme, Windows açılışında başlatma ve iptal edilebilir kuyruk sonu eylemleri.
- Aranabilir seçiciyle 20 arayüz dili; Arapça/Urduca için sağdan sola düzen.
- Chrome/Chromium ve Firefox eklentileri, kimliği doğrulanan yerel mesajlaşma ve açık veri aktarım onayı.
- Video düğmesini sekmenin görünür alanına taşıma, konum hatırlama, kırpılmayan panel, dışarı tıklayarak kapatma ve video/sayfa değişiminde güvenli seçim temizliği.

### Paketler ve testler

Windows kurulum dosyası veya taşınabilir ZIP kullanılabilir. Chromium, Firefox 140+ ve Firefox 120–139 eklentileri ayrı paketlenmiştir. `SHA256SUMS.txt` altı dağıtım dosyasının kimliğini içerir.

Son düzeltmede 39 eklenti ve 6 arayüz testi, kontrollü kaynakla gerçek Chromium panel yerleşimi, Firefox 120/157 yerel entegrasyonu ve yeni Windows kurulum testleri geçti. Değişmeyen motorun önceki 82 testi ayrı tarihli temel kayıt olarak korunur. Test kapsamı ve kayıtları kaynak paketindedir.

Mevcut yerel dosyalar kod imzası taşımıyor; Windows yayıncı veya SmartScreen uyarısı gösterebilir. Chromium eklentisi paketlenmemiş yüklenir. Firefox'ta kalıcı kurulum için Mozilla imzası gerekir. Eklenti mağazalarında yayın ayrı bir işlemdir. DRM ve giriş doğrulamaları otomatik aşılmaz; medya erişimi kaynağa bağlıdır.
