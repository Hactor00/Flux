# Flux 2.2.0

## English

Flux 2.2 improves browser handoff, verified pause/resume and first-run language selection. It also brings the native torrent, source recovery, Debrid and signed updater features developed after 2.0 into this public release.

### New and improved

- Media repair, 14 October: Chromium and Firefox wait for actual desktop acknowledgment. The captured quality can start without another inspection, duplicate inspection controls are removed, optional reinspection preserves the source/name/output, and empty optional fields no longer disconnect older native hosts. This package refresh keeps version 2.2.0; existing 2.2 installations must reinstall the refreshed desktop and reload the matching extension.
- Chromium holds and cancels its browser transfer before filename selection; Firefox intercepts HTTP GET attachment navigation before the file chooser. Flux's separate approval window opens in the foreground. Deferred transfers survive extension background restarts.
- Valid byte ranges work without a strong ETag. Validator-free checkpoints are compared to the remote prefix using SHA-256 before appending. Non-range sources retain saved progress by verifying and discarding a replayed prefix; that verification uses additional network bandwidth.
- The extension popup can show/hide media buttons across open frames. Re-enabling restores dismissed HUDs. Free viewport dragging, per-domain placement, outside-click panel closing and fullscreen support remain available.
- New desktop profiles follow the system language; the extension follows the browser UI language. All 20 supported languages share an English fallback. Manual choices persist. Settings is also directly accessible in the top menu.
- Native v1/v2/hybrid torrents and magnets, configurable seeding, shared bandwidth budgets, selected-file verification and restart recovery.
- Sparse direct positional HTTP writes, stalled-connection recovery, origin-scoped session renewal, bounded native HLS/DASH fallback and encrypted Debrid accounts.
- Signed updates with startup/manual checks, notes, user approval, progress and durable task checkpoints before installation.

### Downloads and upgrade

Windows x64 installer, portable ZIP, Chromium extension, Firefox 140+ extension, Firefox 120–139 extension and source ZIP are attached below. `SHA256SUMS.txt` identifies the packages. `latest.json` and the installer `.sig` support the in-app updater.

Update the desktop and the browser extension together, then refresh media tabs. When another download manager is installed, disable its automatic capture for the browser Flux will handle. Native host registration is automatic with the installer; extension loading remains a separate browser step.

Public 1.7/2.0 users should install 2.2 manually; the new in-app updater is available after this upgrade.

### Validation

194 automated tests passed: 116 Rust, 63 extension and 15 frontend. Separate Windows/browser checks cover Chrome 155, Firefox 120/157, foreground approval without a browser file chooser, media progress/ETA, real torrent peer transfers, window closing, repair and uninstall data retention. Strict TypeScript, Rust formatting, Clippy, production dependency audit and modern Firefox manifest lint passed. See `docs/validation-2.2.md` for evidence and scope.

Update packages are cryptographically signed; Windows executables have no Authenticode publisher certificate. Firefox ZIPs require Mozilla signing for permanent installation. DRM/login challenges, live paid Debrid entitlements and a full live updater installation round trip are outside the local validation record. A nonfatal upstream WebView2 cleanup warning is recorded separately.

## Türkçe

Flux 2.2, tarayıcıdan devralmayı, doğrulanmış duraklatma/sürdürmeyi ve ilk açılıştaki dil seçimini geliştirir. 2.0 sonrasında eklenen yerleşik torrent, kaynak kurtarma, Debrid ve imzalı güncelleyici özellikleri de bu yayındadır.

### Yenilikler

- 14 Ekim medya düzeltmesi: Chrome ve Firefox gerçek masaüstü onayını bekler. Seçilen kalite tekrar inceleme gerektirmeden başlatılır; yinelenen inceleme düğmeleri kaldırılır, isteğe bağlı inceleme kaynak/ad/çıktıyı korur. Boş isteğe bağlı alanlar eski yerel köprünün bağlantısını kesmez. Sürüm 2.2.0 kalır; kurulu 2.2 için yenilenen masaüstü paketi tekrar kurulmalı, eşleşen eklenti yeniden yüklenmelidir.
- Chromium tarayıcı aktarımını dosya seçimi açılmadan bekletir ve iptal eder; Firefox HTTP GET dosya gezinmesini seçim penceresinden önce yakalar. Ayrı Flux onay penceresi ön planda açılır. Bekleyen aktarımlar eklenti arka planı yeniden başladığında korunur.
- Güçlü ETag olmadan Range çalışır. Doğrulayıcısı olmayan checkpoint'lerin başlangıcı uzaktaki veriyle SHA-256 üzerinden karşılaştırılır. Range olmayan kaynaklarda tekrar gelen başlangıç doğrulanıp atılır; ilerleme korunur, ek ağ trafiği tüketilir.
- Eklentinin küçük penceresinden açık çerçevelerde medya düğmeleri açılır/kapatılır. Gizlenen HUD geri getirilebilir. Serbest sürükleme, alan adına göre konum, dışarı tıklayıp paneli kapatma ve tam ekran desteği korunur.
- Yeni masaüstü profili sistem dilini, eklenti tarayıcı dilini izler. 20 dil desteklenir; desteklenmeyende İngilizce kullanılır, elle seçim korunur. Üst menüye Ayarlar erişimi eklenir.
- Yerleşik v1/v2/hibrit torrent ve magnet, paylaşım kuralları, ortak hız bütçesi, seçili dosya doğrulama ve yeniden başlatma kurtarması.
- Seyrek dosyaya konumsal HTTP yazma, takılan bağlantıyı kurtarma, kaynağa bağlı oturum yenileme, yerel HLS/DASH çözümleme ve şifreli Debrid hesapları.
- Açılış/elle güncelleme kontrolü, sürüm notları, kullanıcı onayı, ilerleme ve kurulum öncesi kalıcı görev checkpoint'leri.

### İndirme ve geçiş

Windows x64 kurulum, taşınabilir ZIP, Chromium, Firefox 140+, Firefox 120–139 ve kaynak ZIP aşağıdadır. `SHA256SUMS.txt` paket kimliğini doğrular. `latest.json` ve kurulumun `.sig` dosyası uygulama içi güncelleyici içindir.

Masaüstü ve eklentiyi birlikte güncelle, ardından medya sekmelerini yenile. Başka indirme yöneticisi varsa Flux'un yöneteceği tarayıcıdaki otomatik yakalamasını kapat. Kurulum yerel köprüyü otomatik kaydeder; eklenti yükleme ayrı tarayıcı adımıdır.

Yayımlanan 1.7/2.0 sürümlerinden 2.2'ye elle kurulumla geçilir; yeni uygulama içi güncelleyici bu geçişten sonra kullanılabilir.

### Doğrulama

194 otomatik test geçti: 116 Rust, 63 eklenti, 15 arayüz. Ayrı Windows/tarayıcı testleri Chrome 155, Firefox 120/157, tarayıcı dosya seçicisi olmadan ön planda onay, medya ETA, gerçek torrent eş aktarımı, pencere kapatma, onarım ve kaldırmada veri korumayı kapsar. TypeScript, Rust biçimlendirme, Clippy, üretim bağımlılık ve Firefox manifest denetimleri geçti. Ayrıntılar `docs/validation-2.2.md` içindedir.

Güncelleme paketleri kriptografik imzalıdır; Windows dosyalarında Authenticode yayıncı sertifikası yoktur. Firefox ZIP'lerinin kalıcı kurulumu Mozilla imzası gerektirir. DRM/giriş engelleri, canlı ücretli Debrid yetkileri ve canlı güncelleme kurulumunun tamamı yerel test kaydının dışındadır. İşlevleri engellemeyen WebView2 temizleme uyarısı ayrıca kaydedilmiştir.
