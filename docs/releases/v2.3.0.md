# Flux 2.3.0

## English

Flux 2.3 adds watched torrent folders and a native Linux RPM alongside the Windows installer and portable edition.

- Monitor up to sixteen folders for stable `.torrent` files. Select confirmation or automatic queueing and an optional destination in Settings.
- Preserve duplicate detection across renamed copies, task removal and application restarts. The source torrent files remain untouched.
- Isolate malformed files and missing folders, display errors and retry failed imports with backoff. Scans are bounded and run outside the queue scheduler.
- Install the Linux x86_64 RPM with `sudo dnf install ./Flux-2.3.0-linux-x86_64.rpm`. The package includes the native host, CLI, yt-dlp and the v2/hybrid torrent bridge; dnf installs the declared media and desktop dependencies.
- Register Chromium/Firefox native hosts per user on Linux. Enable XDG autostart if desired. Linux power actions use systemd and require session permission.
- Keep all existing HTTP, media, torrent, browser-handoff, local-history and twenty-language capabilities. Windows retains its signed in-app update flow; RPM updates use dnf.

### Setup and limits

Launch Flux once after installation, install/enable the matching extension and refresh existing media tabs. Browser extensions are separate from desktop host registration. Flatpak/Snap browser confinement may require additional setup. Standard Firefox still requires Mozilla signing for permanent add-on installation.

Monitoring is opt-in and runs while Flux is open. It checks direct folder contents every three seconds and waits for a stable size/modification time before parsing. Limits: 16 folders, 4096 torrent entries, 8 MiB per file and 64 candidates/16 MiB per scan. An identical torrent can still be deliberately imported manually.

Linux RPM support targets Fedora x86_64 with WebKitGTK 4.1, OpenSSL 3, Python 3.10+ and Node 20+. Compatibility with every RPM distribution is not claimed. Native file drag-out remains Windows-only. Windows binaries currently lack an Authenticode publisher certificate; updater signatures are a separate protection. See [validation](../validation-2.3.md).

## Türkçe

Flux 2.3; Windows kurulum ve taşınabilir sürümlerine ek olarak torrent klasörü izleme ve yerel Linux RPM paketi getirir.

- On altı klasöre kadar izleme; değişmesi durmuş `.torrent` dosyalarını algılama, onay veya otomatik kuyruğa ekleme ve isteğe bağlı hedef klasör.
- Dosya yeniden adlandırılsa, görev silinse veya uygulama yeniden açılsa bile aynı dosyayı tekrar eklemeyen kalıcı kayıt. Kaynak torrent dosyaları korunur.
- Bozuk dosya ve erişilemeyen klasörleri diğer indirmelerden ayırma, ayarlarda hata gösterme ve gecikmeli yeniden deneme. Tarama, indirme zamanlayıcısından bağımsız çalışır.
- `sudo dnf install ./Flux-2.3.0-linux-x86_64.rpm` ile Linux kurulumu. Paket; CLI, tarayıcı köprüsü, yt-dlp ve v2/hybrid torrent bileşenini içerir. Medya ve masaüstü bağımlılıklarını dnf kurar.
- Linux kullanıcı hesabına Chromium/Firefox köprü kaydı, isteğe bağlı XDG otomatik başlangıç ve oturum iznine bağlı systemd güç işlemleri.
- Mevcut HTTP, medya, torrent, tarayıcı aktarımı, yerel geçmiş ve yirmi dil korunur. Windows imzalı uygulama güncelleyicisini, Linux RPM paket yöneticisini kullanır.

### Kurulum ve sınırlar

Kurulumdan sonra Flux'u bir kez açın, uygun eklentiyi kurup etkinleştirin ve medya sekmelerini yenileyin. Köprü kaydı, eklentiyi kurmaz. Flatpak/Snap tarayıcıları ek yapılandırma gerektirebilir. Standart Firefox'ta kalıcı kurulum için Mozilla imzası gerekir.

İzleme isteğe bağlıdır ve Flux açıkken çalışır. Klasörlerin doğrudan içeriği üç saniyede bir kontrol edilir; dosya boyutu ve değişiklik zamanı sabitlenmeden içe aktarılmaz. Sınırlar: 16 klasör, 4096 torrent girdisi, dosya başına 8 MiB ve tarama başına 64 aday/16 MiB. Aynı torrent bilerek elle yeniden eklenebilir.

Linux RPM; WebKitGTK 4.1, OpenSSL 3, Python 3.10+ ve Node 20+ sağlayan Fedora x86_64 ortamını hedefler. Her RPM dağıtımı için uyumluluk iddiası yoktur. Dışarı dosya sürükleme Windows'a özeldir. Windows dosyalarında henüz Authenticode yayıncı sertifikası yoktur; güncelleyici imzası ayrı bir korumadır. [Doğrulama kaydı](../validation-2.3.md) ayrıntıları içerir.
