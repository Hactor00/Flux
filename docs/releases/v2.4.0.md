# Flux 2.4.0

Flux 2.4.0 improves media download reliability, makes stream inspection more compatible with strict site CSPs and adds reusable filename prefixes with safe relative folders.

## Changes

- **HLS segment handling:** classify media inputs using their manifests and content hints so valid image-named or extensionless segments served through Flux's local relay are not rejected solely by FFmpeg's segment-extension check.
- **Browser media observation:** stop replacing the page's `window.fetch`. Observe only bounded HLS/DASH response bodies that the page itself reads, while retaining the page's original response and CSP behavior.
- **Filename prefixes:** apply a prefix to file and media downloads, including relative subfolders separated with `/`. The dialog previews the resulting path and offers up to ten recent prefixes.
- **Path safety:** reject absolute paths, traversal segments, unsafe names and directory escapes before creating the destination or queueing a task.
- Keep the existing HTTP, media, BitTorrent, watched-folder, browser integration, Linux RPM and twenty-language functionality.

## Setup

Install Flux 2.4.0 for Windows or Fedora x86_64 RPM from the GitHub release. Install and enable the matching Chromium or Firefox extension, launch Flux once to register the local browser bridge and refresh open tabs. See the root [English README](../../README.md) and [Turkish README](../../README.tr.md) for platform instructions.

## Scope

Media extraction remains dependent on the source site's accessible streams. DRM, CAPTCHA, authentication challenges and inaccessible blob resources are not bypassed. Linux release support targets the Fedora x86_64 environment documented in the platform guide; compatibility with every RPM distribution is not claimed.

# Flux 2.4.0 (Türkçe)

Flux 2.4.0; medya indirme güvenilirliğini artırır, katı CSP kullanan sitelerde akış gözlemini daha uyumlu hale getirir ve güvenli alt klasörlerle yeniden kullanılabilir dosya adı önekleri ekler.

## Değişiklikler

- **HLS segment işleme:** Medya girdileri manifest ve içerik ipuçlarına göre sınıflandırılır. Böylece Flux'un yerel aktarım köprüsünden gelen görsel uzantılı veya uzantısız geçerli segmentler, yalnızca URL uzantısı nedeniyle FFmpeg tarafından reddedilmez.
- **Tarayıcı medya gözlemi:** Eklenti artık sayfanın `window.fetch` işlevini değiştirmez. Sadece sayfanın kendisinin okuduğu, boyutu sınırlı HLS/DASH yanıtlarını gözlemler; sayfanın yanıtını ve CSP davranışını korur.
- **Dosya adı önekleri:** Dosya ve medya indirmelerine, `/` ile ayrılmış göreli alt klasörler dahil önek eklenebilir. Pencere oluşacak yolu önizler ve son kullanılan on öneği sunar.
- **Yol güvenliği:** Mutlak yollar, dizin dışına çıkan `..` parçaları, güvenli olmayan adlar ve indirme klasörünü aşan hedefler işlem veya kuyruk oluşturulmadan reddedilir.
- Mevcut HTTP, medya, BitTorrent, izlenen klasör, tarayıcı bütünleştirme, Linux RPM ve yirmi dil desteği korunur.

## Kurulum

Windows için kurulum paketini veya Fedora x86_64 için RPM'i GitHub sürüm sayfasından indirin. Uyumlu Chromium/Firefox eklentisini kurup etkinleştirin, yerel tarayıcı köprüsünün kaydedilmesi için Flux'u bir kez açın ve açık sekmeleri yenileyin. Platform adımları için kök dizindeki [İngilizce README](../../README.md) ve [Türkçe README](../../README.tr.md) dosyalarına bakın.

## Kapsam

Medya yakalama, kaynak sitenin erişilebilir akışlarına bağlıdır. DRM, CAPTCHA, oturum açma engelleri veya erişilemeyen blob kaynakları aşılmaz. Linux paketi platform kılavuzundaki Fedora x86_64 ortamını hedefler; tüm RPM dağıtımları için uyumluluk iddiası taşımaz.
