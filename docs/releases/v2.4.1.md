# Flux 2.4.1

Flux 2.4.1 is a focused maintenance release for the Windows updater and desktop appearance.

- Fixes repeated update prompts when the update feed offers the installed version or an older one.
- Lets Windows' updater installer manage its restart, avoiding a second app-initiated restart after installation.
- Adds a persistent Light theme alongside Dark in Settings. The selection applies to the main window and separate download/details windows.
- Shows English and Turkish choices in the Windows installer instead of silently choosing the setup language from the system locale.
- Keeps the 2.4 series' media, torrent, browser integration and download features.

Install the Windows x64 setup or Fedora x86_64 RPM from the [Flux 2.4.1 GitHub release](https://github.com/Hactor00/Flux/releases/tag/v2.4.1). The browser extensions are published as separate release assets.

- Windows güncelleyicisinin kurulum sonrası yeniden başlatmayı kendisinin yönetmesini sağlar; uygulama ikinci bir yeniden başlatma başlatmaz.

- 2.4 serisinin medya, torrent, tarayıcı bütünleşmesi ve indirme özelliklerini korur.

Windows x64 kurulumunu veya Fedora x86_64 RPM paketini [Flux 2.4.1 GitHub yayınından](https://github.com/Hactor00/Flux/releases/tag/v2.4.1) indirebilirsiniz. Tarayıcı eklentileri ayrı yayın dosyalarıdır.
