# Flux 2.4.2

- Refreshed desktop design with consistent light/dark surfaces, controls and menus. Settings use sidebar navigation, theme preview cards, a scrolling content area and a fixed save bar. Update actions are clearly separated and styled.
- Fixed the application-version permission used by update checks in the main and settings windows. Disconnected extension popups explain how to start/connect an installed app or download the free desktop app with a prominent GitHub button.

- Browser integration distinguishes local host registration from a live extension connection. Connected versions are shown; closing the browser or disabling/removing the extension clears the connection.
- Repair and setup guidance explain when no connected extension can be found and link to the GitHub downloads. Install/enable the extension, grant its requested permissions and open its popup to connect. Flux cannot inspect closed or restricted browser profiles to prove an extension is uninstalled.
- Chrome and Firefox popups check for new Flux releases on opening. Checks use a six-hour cache and a fifteen-minute retry backoff when offline. Notices link to the official GitHub release; ZIP extensions require manual replacement.
- The desktop warns about outdated connected extensions. Linux gains release availability checks and an RPM download link. Windows retains signed installer updates and the 2.4.1 updater fix.
- Windows setup and uninstall close only the native host belonging to their own installation before replacing/removing its files. Reinstallation is tested with a native port still open.
- New messages are translated into all twenty supported languages. Existing light/dark themes, installer language choice, media capture, file transfers, torrents and watch folders remain available.

**Upgrading:** install Flux 2.4.2, then replace your old Chrome/Firefox extension with the matching ZIP from this release and reopen its popup. The desktop app and browser extension are separate installations. Store signing/publication requirements still apply to permanent browser installation; see the [browser distribution guide](../browser-stores.md).

## Türkçe

- Masaüstü tasarımı yenilendi: ortak açık/koyu yüzeyler, butonlar ve menüler. Ayarlara soldan bölüm seçimi, tema önizleme kartları, kaydırılabilir içerik ve sabit kaydet alanı eklendi. Güncelleme işlemlerinin butonları belirginleştirildi.
- Ana ekran ve ayarlardaki güncelleme kontrolünün kullandığı uygulama sürümü okuma izni düzeltildi. Bağlantısız eklenti popup'ı, kurulu uygulamayı açıp bağlamayı açıklar; ücretsiz masaüstü uygulaması için belirgin bir GitHub indirme düğmesi sunar.

- Yerel köprü kaydı ile canlı eklenti bağlantısı ayrıldı. Bağlı eklenti sürümleri gösterilir; tarayıcı kapanınca veya eklenti devre dışı bırakılınca/kaldırılınca bağlantı kaydı silinir.
- Onarım ve kurulum ekranları, bağlı eklenti bulunamadığında bunu açıklar ve GitHub indirme sayfasını açar. Eklentiyi kurup etkinleştirin, istediği izinleri verin ve açılır penceresini açın. Kapalı veya erişimi sınırlı tarayıcı profillerinde bir eklentinin kesin olarak kaldırıldığını program belirleyemez.
- Chrome ve Firefox popup'ı açılırken yeni sürüm kontrol edilir. Sonuç altı saat saklanır; çevrimdışı hatalarda on beş dakika beklenir. Bildirim resmi GitHub yayınına yönlendirir; ZIP eklentileri elle değiştirilir.
- Masaüstünde eski bağlı eklentiler için uyarı eklenir. Linux yeni sürümü kontrol ederek RPM sayfasına yönlendirir. Windows imzalı kurulum güncellemelerini ve 2.4.1 güncelleyici düzeltmesini korur.
- Windows kurulumu ve kaldırma işlemi, dosyaları değiştirmeden önce yalnız kendi kurulumuna ait yerel köprüyü kapatır. Açık yerel port varken yeniden kurulum test edilir.
- Yeni metinler yirmi dile çevrildi. Açık/koyu tema, kurulum dili seçimi, medya yakalama, dosya indirme, torrent ve izleme klasörleri korunur.

**Güncelleme:** Flux 2.4.2'yi kurduktan sonra eski Chrome/Firefox eklentisini bu yayındaki uygun ZIP ile değiştirip açılır penceresini yeniden açın. Program ve eklenti ayrı kurulur. Kalıcı tarayıcı kurulumu için mağaza imzası/yayın gereklilikleri geçerlidir; [tarayıcı dağıtım kılavuzuna](../browser-stores.md) bakabilirsiniz.
