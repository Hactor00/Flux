# Flux 2.4.3

Flux 2.4.3 lets the GitHub and Chrome Web Store extension distributions connect to the same desktop application.

- The Windows and Linux desktop bridge accepts both the stable GitHub Chromium identity and the Chrome Web Store identity. Install your preferred extension distribution; one is sufficient.
- Extension titles and summaries are localized in all 19 Chrome-supported locales. The runtime keeps its 20 interface languages.
- The dedicated `chrome-store.zip` has no development `key` or self-hosted `update_url`. The ordinary `chrome.zip` retains the stable GitHub identity. Shared runtime code is checked against the source in both packages.
- Windows installer validation exercises Chromium file and media handoff with each identity. Fedora RPM validation checks both registered origins against the installed native host.

**Upgrading:** update the desktop app to 2.4.3. GitHub ZIP users should replace their extension with the matching 2.4.3 archive. Chrome Web Store installation and automatic extension updates become available after Google approves and publishes the store listing; uploading a draft does not publish it. Firefox packages are also versioned 2.4.3 and keep their existing identity.

Both desktop and extension must be installed. Older desktop packages do not recognize the new Chrome store identity. Download availability still depends on the source; DRM, CAPTCHA and access restrictions are not bypassed.

# Flux 2.4.3 — Türkçe

Flux 2.4.3 ile GitHub ve Chrome Web Mağazası eklentileri aynı masaüstü uygulamasına bağlanabilir.

- Windows ve Linux köprüsü hem GitHub eklentisinin sabit kimliğini hem de Chrome mağazasının kimliğini kabul eder. Tercih ettiğiniz tek eklenti dağıtımını kurmanız yeterlidir.
- Eklenti başlıkları ve kısa açıklamalar Chrome'un desteklediği 19 dilde yerelleştirildi. Çalışma zamanındaki 20 arayüz dili korunur.
- Ayrı `chrome-store.zip` paketinde geliştirme `key` ve özel `update_url` alanları bulunmaz. Normal `chrome.zip`, GitHub kimliğini korur. Ortak kodların kaynağa uygunluğu iki pakette de doğrulanır.
- Windows kurulum testi iki kimlikle Chromium dosya ve medya aktarımını sınar. Fedora RPM testi, kurulu yerel köprü üzerinden iki kimliğin de bağlantısını kontrol eder.

**Güncelleme:** masaüstü uygulamasını 2.4.3'e yükseltin. GitHub ZIP kullananlar eklentiyi uygun 2.4.3 arşiviyle değiştirmelidir. Chrome mağazasından kurulum ve otomatik eklenti güncellemeleri, Google mağaza girişini onaylayıp yayınladıktan sonra kullanılabilir; taslağa paket yüklemek yayınlamak değildir. Firefox paketleri de 2.4.3 oldu ve mevcut kimliklerini korur.

Program ve eklenti birlikte kurulmalıdır. Eski masaüstü paketleri yeni Chrome mağazası kimliğini tanımaz. İndirme desteği kaynağa bağlıdır; DRM, CAPTCHA ve erişim kısıtlamaları aşılmaz.
