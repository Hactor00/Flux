# Flux 2.4.4

Fixes `Command plugin:resources|close not allowed by ACL` when checking for updates again after dismissing an earlier offer.

- Grants the specific resource-close command to the local main and Settings windows. Other window permissions are unchanged.
- A failure while releasing an older update no longer discards a valid replacement or blocks the next check. Window cleanup also handles rejected resource-close requests.
- Adds a UI regression for **Check for updates → Later → Check for updates**, including a rejected cleanup request, and a native installer check of the resource-close ACL in both updater windows.
- Retains GitHub/Chrome Web Store browser integration, light/dark themes and the installer language selector. Extension archives use version 2.4.4; no extension runtime behavior changes are required for this desktop fix.

**Upgrading from an affected version:** fully exit Flux, including its tray icon, then launch it and check once before choosing Update. Restarting clears the stale in-memory update resource. If the older version still cannot complete the update, install the [2.4.4 Windows installer](https://github.com/Hactor00/Flux/releases/download/v2.4.4/Flux_2.4.4_x64-setup.exe) over the existing installation. This preserves the local settings and history. Linux RPM users can install the new RPM with their package manager.

# Flux 2.4.4 — Türkçe

Bir güncelleme uyarısına “Daha sonra” dedikten sonra yeniden denetlemede görülen `Command plugin:resources|close not allowed by ACL` hatası düzeltildi.

- Ana pencere ve Ayarlar için gereken kaynak kapatma izni eklendi. Diğer pencerelerin izinleri değişmez.
- Eski güncelleme kaydının temizliği başarısız olsa bile yeni bulunan sürüm gösterilir. Pencere kapanırken oluşan temizlik hataları da ele alınır.
- **Güncellemeleri denetle → Daha sonra → yeniden denetle** akışı, temizliğin hata verdiği durumla birlikte arayüz testine eklendi. Kurulum testi de iki güncelleme penceresinde gerçek kaynak kapatma iznini kontrol eder.
- GitHub/Chrome mağazası uyumu, açık/koyu temalar ve kurulum dili seçimi korunur. Eklenti arşivleri 2.4.4 olarak sürümlenir; bu masaüstü düzeltmesi için eklentinin çalışma biçimi değişmez.

**Etkilenen sürümden güncelleme:** Flux'u tepsi simgesinden de tamamen kapatıp açın. Ardından bir kez güncellemeleri denetleyip Güncelle'yi seçin. Yeniden başlatma, bellekte tutulan eski güncelleme kaydını temizler. Eski sürüm hâlâ güncelleyemiyorsa [2.4.4 Windows kurulumunu](https://github.com/Hactor00/Flux/releases/download/v2.4.4/Flux_2.4.4_x64-setup.exe) mevcut kurulumun üzerine çalıştırabilirsiniz; yerel ayarlar ve geçmiş korunur. Linux RPM kullanıcıları yeni RPM'i paket yöneticisiyle kurabilir.
