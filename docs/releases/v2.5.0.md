# Flux 2.5.0

Flux 2.5.0 refreshes the browser extension, adds light/dark/system themes and improves video controls in expanded and fullscreen players. Windows, Linux and browser packages share the same version.

## Changes

- Redesigned popup with media, page-link and transfer-queue tabs, item counts, connection details and empty states.
- Redesigned extension settings with persistent light, dark and system themes shared by the popup and settings page.
- Compact 30-pixel video toolbar with smaller controls. It follows the player into modal and fullscreen containers; clicks stay within the toolbar instead of triggering the site's viewer.
- Background video controls are hidden while a modal player is active. Quality, audio/subtitle selection, dragging, closing and per-site positioning remain available.
- Desktop update screens show the installed version. Updater resource permissions and repeated-check safeguards from 2.4.4 remain enabled.
- All-site automatic detection remains enabled. The redundant activeTab permission was removed; broad HTTP/HTTPS access remains necessary for automatic detection across sites.
- Both GitHub and Chrome Web Store extension identities continue to connect to the same desktop application.

## Packages and updating

Windows users can use **Settings → Updates → Check for updates**, or download the installer/portable ZIP. Fedora users can install the RPM with `sudo dnf install ./Flux-2.5.0-linux-x86_64.rpm`.

Use `Flux-2.5.0-chrome.zip` for Chrome, Edge, Brave and Chromium, `Flux-2.5.0-firefox.zip` for Firefox 140+, and `Flux-2.5.0-firefox-120.zip` for Firefox 120–139. Extension ZIPs work on both Windows and Linux. Replace the previous unpacked extension and refresh existing tabs. Store submission ZIPs are separate; store availability depends on each store's approval. Firefox ZIPs require Mozilla signing for permanent installation.

Windows updater packages are signed with the Flux update key. Windows executables do not carry an Authenticode publisher certificate, and the RPM is not RPM-signed. SHA-256 checksums identify the published assets.

## Validation

Extension tests, frontend tests and production builds passed locally. Production UI modules were checked in isolated Chromium across all 20 languages, including tab navigation, selection, native handoff, theme persistence and offline guidance. Actual pointer interactions were checked in native dialogs, transformed custom modals and fullscreen containers. Firefox 120 and 157 integration checks passed. The Linux RPM was built on Ubuntu 24.04 and installed on Fedora 43, exercising desktop startup, verified HTTP transfer, native messaging, torrent-folder watching and database integrity.

Website media availability remains source-dependent. Isolated player fixtures do not establish compatibility with every live website.
