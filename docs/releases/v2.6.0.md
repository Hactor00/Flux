# Flux 2.6.0

Flux 2.6.0 makes download choices clearer and connects both Firefox distributions to the same desktop application.

- **Firefox store and GitHub support:** the native host authorizes both `firefox@fluxdownload.org` and `flux@flux-download.local`, while retaining the existing Chrome store and GitHub identities. Open Flux once after updating to refresh the browser registration.
- **Download information:** ordinary file sources are inspected before starting and display their reported size. Media format sizes remain marked as estimates. Sources that do not provide a size are shown as unknown.
- **Torrent choices:** inspect local or HTTP `.torrent` metadata and select the included files before queueing. HTTP torrent links offer separate actions to download their contents or save only the `.torrent` file. Magnet file selection remains available in task details once metadata arrives.
- **Video previews:** task details can decode a preview frame from data already downloaded. Availability depends on the file format and on how much readable data has arrived. Preview does not fetch another remote media source.
- **Portable data:** new portable packages keep settings/history in `Data/Flux` and default downloads in `Data/Downloads`. Paths inside the portable folder are adjusted when it moves. The PortableApps layout ZIP includes a launcher; it is not a PortableApps.com-certified release. Browser sessions protected by Windows may need refreshing on another computer.
- **Updates:** installed Windows editions retain signed updates and existing local data. Portable editions open release downloads so their Data folder can be retained; Linux uses RPM upgrades. Both browser distributions check release information periodically and when opening the popup. Store extension updates are delivered by the browser after store approval; unpacked extensions are replaced manually.
- **Refined interfaces:** clearer size summaries, torrent actions and preview panels on desktop, plus updated extension cards and store/setup guidance on the website.
- **Media approval size:** sizes already resolved for browser media are retained in the desktop approval window, including the selected video/audio pair. Direct media files also support source-size inspection. Media sizes remain marked as estimates.
- **Completion window:** newly completed downloads open a compact window with file/folder actions when completion notifications are enabled. Existing history does not reopen completion windows at startup.
- **Selection controls:** toolbar and context-menu actions follow the selected task's state. Click empty space or press Escape to clear selection; filtering also clears it.
- **Store installation links:** English and Turkish READMEs link directly to the Chrome Web Store and Mozilla Add-ons, with the current review status and desktop requirements.

Windows x64 installer, Windows portable, PortableApps layout, Linux x86_64 RPM, Chromium and Firefox packages use version 2.6.0. Chrome/Mozilla submission ZIPs are build artifacts for the publisher and are not included as public GitHub downloads. Matching media runtime source and licenses are available separately in `Flux-2.6.0-media-source.zip`; license notices stay in the application packages.

After upgrading from 2.5.0, open Flux and refresh your browser tabs. Existing GitHub and Chrome store extensions remain supported. Firefox store approval and availability are controlled by Mozilla.

The 2.6.0 packages were refreshed with these desktop fixes without changing the version number. If you already installed an earlier 2.6.0 package, download and install the refreshed package manually; the updater only offers versions newer than the installed version. Installed 2.5.0 copies can use the signed updater normally.
