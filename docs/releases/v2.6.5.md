# Flux 2.6.5

Flux 2.6.5 makes download windows smaller, improves the desktop at different window sizes and introduces optional usage statistics with an explicit choice.

- Edit the filename, select the destination through the folder button and see quality/known size directly in the compact download window. Details expands the advanced controls.
- The progress window has a visible close-on-completion preference, with the separate completion notification retained.
- Responsive list columns, an adaptive sidebar, optional compact rows and a conditional selection panel reduce wasted space. System, light and dark themes share the same controls.
- Desktop and browser interfaces retain all 20 supported languages. The Windows installer offers those 20 choices and hands the language to new app profiles. Some uncommon maintenance/runtime messages use an English fallback. Silent upgrades retain user preferences. Linux installer interfaces belong to the distribution's package manager; Flux supports all 20 languages.
- Refreshed Chromium/Firefox popup and settings, explicit desktop connection guidance and official store links. Both Firefox identities and both Chromium origins remain authorized. Approved store extensions update through the browser; GitHub ZIP copies use the release notice and manual package replacement.
- Optional statistics are off until accepted. Later means seven days; Not now means 45 days; permanent reminder suppression is available in settings. Withdrawal stops measurement and queues deletion. The private server/dashboard requires separate deployment; it is not a public GitHub asset. [Data notice](../usage-statistics.md).
- The existing updater verification key is retained. Installed Windows copies can update from 2.6.0; portable copies open release downloads and Linux copies use the package manager.

Windows x64 installer, portable, PortableApps layout, Fedora x86_64 RPM, Chromium and two Firefox packages are included. Store-only submission archives stay separate from public release assets. Dependency licenses and matching media runtime source remain included.

The published source archive contains the version-specific validation report, package hashes and workflow evidence. Store approval and website/server deployment have separate completion states.
