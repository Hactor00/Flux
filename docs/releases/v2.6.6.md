# Flux 2.6.6

Flux 2.6.6 fixes the layout of desktop windows introduced in 2.6.5.

- Download and progress windows attach content measurement after their dialogs mount. Opening Details expands the window and closing Details restores its compact size.
- The download button keeps its intended width. Queue and close-on-completion checkboxes remain compact, with their text beside them.
- Completion buttons align consistently; completion and power countdown windows also fit their contents.
- Update and confirmation dialogs remain usable on short screens. Update actions stay visible while release notes scroll. Maximized windows retain their size.
- Desktop, browser packages and the separate website package use version 2.6.6. Existing browser identities, supported languages, settings, history and optional statistics behavior are retained.

The updater verification key is unchanged. Installed Windows users can update in the app; the release checks upgrade preservation from 2.6.5. Portable users replace their application files while keeping Data, and Linux users install the updated RPM. Approved store updates arrive through the browser; GitHub extension ZIPs retain the update notice and manual replacement workflow.

Windows x64 installer/portable/PortableApps layout, Linux x86_64 RPM, Chromium and both Firefox packages are included. Store-only archives remain separate from public GitHub assets. The source archive contains version-specific validation records and package/workflow provenance. Store approval and website deployment are separate steps.
