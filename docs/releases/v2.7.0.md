# Flux 2.7.0

Flux 2.7.0 fixes downloads that remained queued after pausing the queue, improves compatibility with restrictive download servers, and adds an optional transparent desktop appearance.

- **Start downloads reliably:** starting or resuming a download re-enables the scheduler after “Pause all”; unrelated paused tasks stay paused.
- **Adapt to server limits:** transient errors, throttling and stalled connections reduce concurrent requests automatically while preserving verified download offsets and respecting server retry delays.
- **Keep healthy streams connected:** a short pause or a change in download speed no longer forces a reconnect. Range probes rejected with an unsupported-method response or an unqualified 503 can fall back to a single plain stream.
- **Clearer speed and time estimates:** a rolling speed measurement reduces brief spikes and zero-speed flashes without counting reused bytes as new progress.
- **Return after updating:** installed updates reopen the main window instead of inheriting a background-only launch. Existing downloads and preferences remain preserved.
- **Polished controls:** task removal uses consistent, separated cancel and remove buttons. Appearance settings include an optional translucent backdrop, with an opaque fallback when native effects are unavailable.
- Desktop, Chrome and Firefox packages report version 2.7.0. Store upload packages are distributed separately from public GitHub assets.

Windows installed versions can use the startup update notice or Settings → Updates. Portable and Linux users can download the matching package from this release.
