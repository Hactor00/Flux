# Flux 2.4.2 validation

Release checks cover extension/frontend regressions, twenty locale catalogs, TypeScript/production builds, Rust tests/lint, authenticated native connection lifetime, onboarding without an installed extension, live connect/disconnect, Windows installed-package behavior, media/torrents and an installed Fedora RPM. The exact package report is generated by the release workflows in `docs/validation/release.json` inside the source archive. `release-info.json` identifies the source commit and the Windows/Linux workflow runs. Older reports are historical, not evidence for 2.4.2.

Connection tests distinguish host registration from a real extension/native-port session and reject unauthenticated presence requests. Version-check tests cover same/older/invalid versions, cache refresh, parallel checks and offline behavior. Chrome and Firefox packages share the same runtime sources. See the [release](https://github.com/Hactor00/Flux/releases/tag/v2.4.2) for verified package identities and completed build runs.

Desktop checks exercise settings navigation with English, Turkish, German and Arabic labels, horizontal overflow, the fixed save bar, persisted light/dark selection and the application-version permission used by the updater. Windows installer checks include replacement while its own native host is still open.

Automated checks do not establish compatibility with every media website, browser profile, Linux distribution, Flatpak or Snap browser. DRM, CAPTCHA and unavailable streams remain outside the compatibility guarantee. ZIP extensions report updates but cannot install themselves silently.

## Türkçe

Sürüm kontrolleri eklenti ve arayüz regresyonlarını, yirmi dil kataloğunu, TypeScript/üretim derlemesini, Rust testlerini/lint denetimini, kimliği doğrulanmış yerel bağlantının ömrünü, eklentisiz ilk kurulum durumunu, bağlantı kurma/koparmayı, Windows kurulum paketini, medya/torrentleri ve Fedora RPM kurulumunu kapsar. Paket raporu iş akışlarında üretilip kaynak arşivindeki `docs/validation/release.json` dosyasına eklenir. `release-info.json` kaynak commit'i ve Windows/Linux iş akışlarını belirtir. Önceki raporlar geçmişe aittir; 2.4.2 için kanıt olarak kullanılmaz.

Bağlantı testleri köprü kaydını gerçek eklenti/yerel port oturumundan ayırır ve kimlik doğrulaması olmayan bağlantı bildirimini reddeder. Sürüm kontrol testleri aynı/eski/geçersiz sürümleri, önbelleği, paralel istekleri ve çevrimdışı davranışı kapsar. Chrome ve Firefox aynı çalışma zamanı kaynaklarını paylaşır. Tamamlanan derlemeler ve doğrulanmış paketler için [yayını](https://github.com/Hactor00/Flux/releases/tag/v2.4.2) inceleyin.

Masaüstü kontrolleri İngilizce, Türkçe, Almanca ve Arapça etiketlerle ayar bölümlerini, yatay taşmayı, sabit kaydet alanını, açık/koyu tema kaydını ve güncelleyicinin kullandığı uygulama sürümü okuma iznini sınar. Windows kurulum testi, kendi yerel köprü işlemi açıkken dosyaların değiştirilmesini de içerir.

Otomatik testler tüm medya siteleri, tarayıcı profilleri, Linux dağıtımları veya Flatpak/Snap tarayıcıları için uyumluluk garantisi vermez. DRM, CAPTCHA ve erişilemeyen akışlar bu garantinin dışındadır. ZIP eklentileri güncellemeyi bildirir; kendilerini sessizce kuramaz.
