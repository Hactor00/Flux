# Flux 2.4 validation

Release validation is recorded against the exact 2.4.0 package artifacts and GitHub Actions runs. This document will contain the run links, test counts, package hashes and tested platform scope after the Windows and Linux release workflows complete. Historical 2.3 evidence is available in [validation-2.3.md](validation-2.3.md) and is not evidence for 2.4.0.

## Scope

The 2.4 release checks cover the shared extension build, localization catalogs, strict TypeScript and frontend tests; Rust tests, formatting and Clippy; browser handoff and installed Windows package behavior; and the Linux RPM installed-package workflow. The release report will distinguish automated regressions from external-site compatibility and other untested scenarios.
