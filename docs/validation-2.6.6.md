# Flux 2.6.6 validation

The machine-readable release report is generated by release workflows in `docs/validation/release.json` inside the source archive. `release-info.json` identifies the successful Windows and Linux workflows and source commit. Earlier records are historical and do not establish this version's result.

Window regression checks exercise the production frontend in an isolated browser with delayed native IPC fixtures. They check all twenty languages in the compact download dialog, expansion/collapse, compact checkboxes, progress, completion, countdown, settings, update and confirmation dialogs, and the main window at several viewport sizes. Native WebView tests separately check actual window growth/collapse, visible download/completion actions, media size and selection behavior.

Release gates also include localization parity, frontend and extension regressions, Rust tests and Clippy, native browser identities, installed Windows upgrade preservation from 2.6.5, signed updater artifacts, and installed Fedora RPM behavior. Optional statistics and its separately deployed server retain their existing consent and privacy checks. The website bundle is verified locally across twenty languages; it is delivered separately for operator upload.
